# 05 · 内容维护手册

日常维护网站 99% 的操作都在这里。改完保存，`npm run dev` 打开的浏览器会自动刷新。

## 前置准备

```bash
cd 项目目录
npm install    # 首次 / 换电脑后
npm run dev    # 启动预览 http://localhost:4321
```

## 任务一：改成我的真实信息

| 改什么 | 文件 | 改哪里 |
|--------|------|--------|
| 姓名、一句话介绍、城市 | `src/content/site/info.md` | name / tagline / location |
| 邮箱、GitHub、微信等 | `src/content/site/info.md` | email / github / wechat … |
| 头像 | 图片放 `public/` 下 | avatar 填 `/图片名.jpg` |
| 关于我正文 | `src/content/about.md` | `---` 下方的正文 |
| 技能 | `src/content/about.md` | skills 列表 |
| 教育背景 | `src/content/about.md` | education 列表 |

YAML 格式注意事项：

- 每个字段冒号后要有空格：`name: 张三`（不是 `name:张三`）
- 想留空的字段写 `""`，不要删掉这行
- 字段值一般不用加引号；值里含冒号等特殊符号时加引号

## 任务二：加一条经历

1. 复制 `src/content/experience/job-2.md`，改名 `job-3.md`（文件名别和已有的重复即可）
2. 改 frontmatter：公司、职位、时间段（period 原样显示）、亮点列表
3. `order` 填比现有最大号更大的数字（保证排在最前面）

## 任务三：加一个项目

同经历：复制 `src/content/projects/` 里的示例文件 → 改字段。`link` / `github` 填完整网址（含 https://），还没上线就留 `""`。

## 任务四：改配色 / 圆角 / 阴影

打开 `src/styles/global.css`，只动最上面的 `:root { }` 变量区：

```css
--color-bg: #faf6f0;      /* 改成你想要的背景色 */
--color-accent: #c4703f;  /* 改成你想要的强调色 */
--radius-md: 14px;        /* 圆角大小 */
```

颜色值用 16 进制（# 开头 6 位）。想选色：搜 "color picker" 在线取色。

## 任务五：加一个新页面（进阶）

1. 在 `src/pages/` 下新建 `photos.astro`（文件名就是网址 /photos/）
2. 内容骨架：

```astro
---
import BaseLayout from '../layouts/BaseLayout.astro';
---

<BaseLayout title="照片" description="我的照片">
  <section class="container page-head">
    <h1>照片</h1>
  </section>
</BaseLayout>
```

3. 在 `src/components/Header.astro` 的 navItems 里加一行：

```js
{ href: '/photos/', label: '照片', match: '/photos/' },
```

## 任务六：把改动"存档"（git 提交）

```bash
git status                    # 看看改了什么
git add .                     # 全部暂存
git commit -m "更新个人信息"    # 提交，附一句说明
```

## 任务七：重新构建

内容改完后（部署前，或想双击 HTML 看效果时）：

```bash
npm run build    # 生成 dist/，双击 dist/index.html 即可打开
```

## 常见报错排查

| 现象 | 原因 | 解决 |
|------|------|------|
| 构建报错、指出某个 .md 文件 | frontmatter 格式不对（缩进/冒号空格） | 对照示例文件逐行检查 |
| 报"字段类型错误" | 比如 order 写了文字 | order 改成数字 |
| 页面没显示新内容 | 浏览器缓存 | 强制刷新（Ctrl+F5） |
| dev 提示端口被占用 | 上次的服务器没停 | `astro dev stop` |
