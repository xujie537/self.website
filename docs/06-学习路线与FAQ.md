# 06 · 学习路线与 FAQ

## 常见问题

### Q：怎么把这个网站放到网上让大家访问？

A：需要选一个免费托管平台（Cloudflare Pages / GitHub Pages / Vercel 等），并把项目推到 GitHub 仓库。这是项目的下一步，做之前会列方案给你选。核心操作将来只有：`git push` + 平台自动构建。

### Q：为什么浏览器打开 localhost:4321 就"有网站"了？

A：`npm run dev` 在**你的电脑上**启动了一个临时服务器，只在本机和同一 Wi-Fi 的局域网内可访问，它并不是互联网上的网站。部署上线后才人人可访问。

### Q：dist/ 是什么？

A：`npm run build` 的产物 —— 纯 HTML/CSS 文件，这就是网站本体，复制到任何静态托管平台都能跑。`node_modules/`、`src/` 都只是"生产它的车间"。

### Q：我想改字体？

A：改 `global.css` 里的 `--font-sans` 变量。因为 Windows 和手机上的字体不同，所以写了字体栈（多个备选，依次尝试，前面没有就用后面的）。

### Q：遇到报错怎么办？

A：三步走：1) 完整读一遍报错信息，它通常会说哪个文件哪一行；2) 对照 05 篇的排查表；3) 还解决不了就把报错信息发给 Claude 或去搜索引擎搜。

### Q：这个项目为什么要 git 管理？

A：每次"存档"（commit）后，任何一次改坏都可以一键回退。而且将来部署到 GitHub Pages / Vercel 等平台，都要通过 git 把代码推上去。**不 commit 就无法部署**，这是个人项目最容易漏掉的习惯。

## 学习路线（由近到远）

1. **先把本网站当玩具**：改内容（05 篇）→ 改配色 → 加一个页面，培养"改哪里"的直觉
2. **补基础**（如果完全没学过前端）：
   - HTML / CSS：MDN 官方教程（developer.mozilla.org/zh-CN/docs/Learn），跟着做一两个静态页面
   - JavaScript：了解变量、函数、数组的 map 就够了
   - Git：任意入门教程的前两章（add / commit / push 就够日常用）
3. **理解 Astro**：官方教程 docs.astro.build/zh-cn/tutorial/，跟着做一遍博客
4. **回头看本项目**：重读 04 篇代码详解，你会发现全都懂了
