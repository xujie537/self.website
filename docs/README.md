# 技术文档 · 学习指南

这份文档包记录了这个个人网站项目从零到一的完整过程：做了什么、为什么这么做、每个文件是什么意思。写给想看懂并学会维护这个项目的人，零基础也可以读。

## 怎么读

按顺序读，每篇都写得很细：

| 篇目 | 内容 | 适合 |
|------|------|------|
| [01 背景知识](01-背景知识.md) | 网站是怎么运作的，技术名词解释 | 零基础必读 |
| [02 开发流程与方法](02-开发流程与方法.md) | 我们实际的工作步骤、命令、决策方法 | 想了解完整流程 |
| [03 项目结构](03-项目结构.md) | 每个文件/文件夹是干什么的 | 建立整体印象 |
| [04 代码详解](04-代码详解.md) | 逐个文件、逐段解释代码含义 | 想看懂代码 |
| [05 内容维护手册](05-内容维护手册.md) | 如何自己改内容、加经历、加项目 | 日常维护查询 |
| [06 学习路线与FAQ](06-学习路线与FAQ.md) | 常见问题、接下来怎么深入学习 | 迷茫时看 |

## 快速上手

想先把网站跑起来看效果：

```bash
npm install    # 首次使用（或换电脑后）：安装依赖
npm run dev    # 启动本地预览，浏览器打开 http://localhost:4321
```

停止预览服务：`astro dev stop`。
